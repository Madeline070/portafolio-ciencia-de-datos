# Análisis Exploratorio de Datos (EDA) y Visualización de Ventas con Python

## 1. Descripción del proyecto

Este proyecto tiene como finalidad realizar un Análisis Exploratorio de Datos (EDA) sobre la información de ventas de una empresa de productos de consumo, utilizando Python y herramientas de visualización.

El análisis permite identificar patrones de comportamiento, tendencias, relaciones entre variables, diferencias en el rendimiento de productos y posibles valores atípicos que pueden influir en la interpretación de los resultados.

## 2. Objetivos

- Explorar y comprender la estructura de los datos consolidados.
- Identificar las variables relevantes para el análisis comercial.
- Analizar la distribución de las ventas.
- Identificar tendencias de ventas a lo largo del tiempo.
- Explorar relaciones entre diferentes variables.
- Comparar el rendimiento de productos, categorías y segmentos.
- Detectar posibles valores atípicos y anomalías.
- Obtener insights que apoyen la toma de decisiones empresariales.

## 3. Herramientas y tecnologías

- **Python:** procesamiento y análisis de datos.
- **Pandas:** manipulación de DataFrames.
- **NumPy:** operaciones numéricas.
- **Matplotlib:** generación de gráficos.
- **Seaborn:** visualizaciones estadísticas.
- **Jupyter Notebook:** desarrollo y documentación del análisis.

## 4. Desarrollo del análisis

### Carga y exploración de datos
Se utilizó el conjunto de datos consolidado en la práctica anterior para explorar la información y seleccionar las variables relevantes.

### Distribución de ventas
Se utilizaron histogramas y diagramas de caja (boxplots) para analizar la distribución de las ventas e identificar posibles valores atípicos.

### Análisis de tendencias
Se generaron gráficos de líneas para estudiar la evolución de las ventas a través del tiempo, considerando diferentes productos y categorías.

### Relación entre variables
Se utilizaron gráficos de dispersión para explorar posibles relaciones y correlaciones entre variables relevantes.

### Análisis geográfico
Se exploró el comportamiento de las ventas por región, cuando la información disponible lo permitió.

### Identificación de anomalías
Se utilizaron diagramas de caja para detectar observaciones que presentaran comportamientos inusuales.

## 5. Resultados e insights

Las visualizaciones permitieron explorar el comportamiento de las ventas, comparar el desempeño de los productos e identificar patrones relevantes para el negocio.

Los hallazgos obtenidos sirven como base para posteriores análisis de segmentación, elaboración de dashboards y desarrollo de modelos predictivos.

## 6. Entregables

- Notebook de Jupyter (.ipynb) con el código y el análisis exploratorio.
- Gráficos y visualizaciones generados durante el proceso.
- Explicaciones e insights derivados de cada visualización.
- Archivos gráficos exportados en formato PNG o JPEG.

## 7. Conclusión

El Análisis Exploratorio de Datos permitió transformar los registros de ventas en información visual y comprensible, facilitando la identificación de tendencias, patrones y posibles anomalías. Esta etapa constituye una base importante para el desarrollo de modelos analíticos y la toma de decisiones basadas en datos.
