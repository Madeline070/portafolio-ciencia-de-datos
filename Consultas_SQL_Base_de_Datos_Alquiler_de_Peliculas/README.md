# Consultas SQL: Base de Datos de Alquiler de Películas

## Descripción del proyecto
En esta práctica se trabajó con una base de datos basada en un sistema de alquiler de películas, que contiene información sobre actores, películas, clientes, tiendas y alquileres.

El objetivo fue utilizar SQL para consultar, analizar y relacionar la información, obteniendo respuestas a diferentes preguntas sobre las películas, los actores y los clientes.

## Objetivos
- Realizar consultas SQL para obtener información específica.
- Analizar datos de películas y actores.
- Consultar información relacionada con las tiendas y sus clientes.
- Utilizar funciones y herramientas de SQL para responder las preguntas planteadas.
- Interpretar los resultados y obtener conclusiones.

## Herramientas utilizadas
- SQL
- Base de datos de alquiler de películas.

## Entregables
- Archivo SQL con las consultas realizadas.
- Documento PDF con las respuestas, resultados y conclusiones de los análisis.

## Conclusión
Esta práctica permitió reforzar el uso de SQL para consultar y analizar bases de datos relacionales, así como interpretar los resultados obtenidos para responder preguntas y generar información útil.
