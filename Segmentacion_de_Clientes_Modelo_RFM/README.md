# Segmentación de Clientes mediante el Modelo RFM

## 1. Descripción del proyecto

Este proyecto tiene como objetivo realizar una segmentación de clientes mediante el modelo RFM (Recency, Frequency, Monetary), una metodología utilizada en Ciencia de Datos y Marketing para analizar el comportamiento de compra de los clientes.

A través del análisis de la recencia, frecuencia y valor monetario de las compras, se busca identificar diferentes perfiles de clientes y comprender sus patrones de consumo.

## 2. Objetivos

- Analizar el comportamiento de compra de los clientes.
- Calcular los indicadores de recencia, frecuencia y valor monetario.
- Identificar diferentes segmentos de clientes.
- Reconocer clientes frecuentes y de mayor valor.
- Identificar oportunidades de fidelización y retención.
- Generar conclusiones que apoyen las estrategias comerciales.

## 3. Herramientas y tecnologías

- **Python:** procesamiento y análisis de datos.
- **Pandas:** manipulación de DataFrames.
- **NumPy:** operaciones numéricas.
- **Matplotlib y Seaborn:** visualización de resultados.
- **Jupyter Notebook:** desarrollo y documentación del ejercicio.

## 4. Metodología RFM

### Recency (Recencia)
Mide el tiempo transcurrido desde la última compra realizada por cada cliente. Permite identificar qué clientes han comprado recientemente.

### Frequency (Frecuencia)
Representa el número de compras realizadas por cada cliente durante el periodo analizado.

### Monetary (Valor monetario)
Calcula el importe total de las compras realizadas por cada cliente, permitiendo identificar a quienes generan mayor valor económico.

## 6. Resultados y aplicaciones

La segmentación RFM permite identificar distintos perfiles de clientes según sus hábitos de compra y valor comercial.

Esta información puede utilizarse para diseñar estrategias de marketing, programas de fidelización, campañas de recuperación de clientes y acciones comerciales personalizadas.
