# Proyecto de Pronóstico de Ventas: Vanish y Lysol

## Descripción

El objetivo de este proyecto es desarrollar un modelo predictivo para estimar las ventas futuras de productos clave como Vanish y Lysol, utilizando datos históricos de ventas.

## Objetivos

- Preparar y analizar los datos históricos.
- Seleccionar una técnica de modelado adecuada.
- Entrenar y validar un modelo predictivo.
- Evaluar su desempeño mediante métricas de error.
- Generar pronósticos de ventas futuras.
- Proponer recomendaciones basadas en los resultados.

## Metodología

1. Carga y preparación de los datos.
2. Selección de la técnica de modelado.
3. División de datos en entrenamiento y prueba.
4. Construcción y entrenamiento del modelo.
5. Evaluación y optimización.
6. Generación de predicciones.
7. Interpretación de resultados.

## Herramientas

- Python
- Pandas y NumPy
- Jupyter Notebook
- Herramientas de modelado estadístico y predictivo

## Entregable

Notebook de Jupyter con el código, los gráficos, las explicaciones y los resultados del proceso de construcción y validación del modelo.
