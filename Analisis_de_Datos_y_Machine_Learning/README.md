# Análisis de Datos y Machine Learning: Aplicaciones y Predicción

## 1. Descripción del proyecto

Este proyecto integra dos ejercicios prácticos de Ciencia de Datos y Machine Learning utilizando Python. Su propósito es aplicar técnicas de análisis exploratorio, visualización, procesamiento de datos y aprendizaje automático para resolver diferentes problemas mediante información real.

El proyecto se divide en dos partes: el análisis de aplicaciones de Google Play Store y la construcción de modelos predictivos para la clasificación de riesgo cardíaco y el reconocimiento de números escritos a mano.

## 2. Objetivos generales

- Aplicar técnicas de exploración y análisis de datos.
- Identificar patrones y relaciones entre variables.
- Comprender los factores que influyen en las calificaciones de las aplicaciones.
- Desarrollar modelos de Machine Learning supervisado.
- Entrenar y evaluar algoritmos de clasificación.
- Aplicar modelos de reconocimiento de imágenes.
- Interpretar los resultados y generar conclusiones basadas en datos.

## 3. Herramientas y tecnologías

- **Python:** programación y análisis de datos.
- **Pandas:** manipulación y procesamiento de información.
- **NumPy:** operaciones numéricas.
- **Matplotlib y Seaborn:** visualización de datos.
- **Scikit-learn:** construcción y evaluación de modelos de Machine Learning.
- **Jupyter Notebook:** desarrollo y documentación de los ejercicios.
- **Paint:** creación de imágenes para el ejercicio de reconocimiento de números.

## 4. Desarrollo del proyecto

### Parte I. Análisis exploratorio de aplicaciones de Google Play Store

Se realizó un análisis de los datos de aplicaciones disponibles en Google Play Store con el objetivo de identificar qué características pueden influir en su popularidad y valoración por parte de los usuarios.

Se analizaron variables como:

- Categoría de las aplicaciones.
- Tamaño.
- Precio.
- Número de instalaciones.
- Calificaciones y reseñas.

Se utilizaron técnicas de exploración, limpieza de datos y visualización para identificar patrones y relaciones entre las variables.

### Parte II. Aprendizaje supervisado con Machine Learning

Esta sección comprende dos ejercicios de aplicación de modelos predictivos.

**Ejercicio 1. Clasificación de riesgo cardíaco**

Se desarrolló un modelo de clasificación para identificar patrones asociados con la probabilidad de presentar un ataque cardíaco, utilizando datos de pacientes.

El proceso incluyó:

- Análisis exploratorio de datos.
- Preparación y transformación de variables.
- Entrenamiento del modelo de clasificación.
- Evaluación del desempeño.
- Generación e interpretación de predicciones.

**Ejercicio 2. Reconocimiento de números escritos a mano**

Se implementó un ejercicio de reconocimiento de imágenes mediante Machine Learning, utilizando números dibujados manualmente en Paint.

El objetivo fue procesar una imagen y utilizar un modelo entrenado para identificar qué número representa.

## 5. Resultados y aprendizajes

El desarrollo de ambas partes permitió aplicar conocimientos de análisis exploratorio, procesamiento de datos, visualización y aprendizaje supervisado.

Se trabajó con problemas de diferentes contextos, desde el análisis del comportamiento de aplicaciones móviles hasta la clasificación de información médica y el reconocimiento de imágenes.

## 6. Entregables

- Notebook de Jupyter (.ipynb) con los ejercicios, código y resultados.
- Documento Word o PDF con las conclusiones del análisis.
- Resultados y visualizaciones generados durante el desarrollo.

## 7. Conclusión

Este proyecto demuestra la aplicación de herramientas de Ciencia de Datos y Machine Learning para analizar información, identificar patrones y desarrollar soluciones predictivas.

La integración de los dos ejercicios permitió fortalecer habilidades de programación con Python, análisis exploratorio, clasificación y reconocimiento de imágenes, mostrando la utilidad del aprendizaje automático en diferentes áreas de aplicación.
